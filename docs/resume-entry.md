AgentForge - AI 智能体助手平台 2026.11- 至今

技术栈：Spring Boot + Spring AI + MyBatis + PostgreSQL/pgvector + React + TypeScript

项目背景：面向企业知识库问答与自然语言查库场景，从零构建可配置化的通用 AI Agent 平台，支持 Agent 自主决策调用工具、多模型动态绑定与 SSE 过程实时推送，全程测试驱动开发（77 个单元/集成测试，真实模型端到端与界面自动化双验收）。

实现 Think-Execute 决策循环：关闭框架内置工具自动执行，以手动 ToolCallingManager 自主掌控「思考—执行—结果回填」全流程，六条执行路径（直接回答/单轮工具/多轮工具/terminate 主动终止/超步数/异常）全部单测覆盖；修复参考实现的单例装配共享状态并发缺陷，多会话互不串扰。

统一 Tool 接口 + 动态装配 + 可插拔模型注册：抽象统一工具接口按「固定/可选」分类，运行期读取 Agent 配置经 MethodToolCallbackProvider 动态装配；SQL 查询工具设计四层护栏（语句白名单/多语句拒绝/强制 LIMIT 包裹/数据库只读角色纵深防御）；模型注册表以 Bean 名与配置值三方对齐并加装配期一致性测试，新增模型/工具零侵入。

pgvector + Embedding API 检索链路：Markdown 按标题语义分块（策略接口化，可替换切分算法），自写 TypeHandler 处理 float[] 与向量类型映射，上传失败整体回滚杜绝"半入库知识库"；知识库列表注入决策提示词，与检索工具参数构成"导航+执行"闭环，Agent 可自主选择知识库检索。

SSE 长连接 + 异步流式推送 + 测试工程：SseEmitter 连接池按会话隔离监听器，四类事件（思考/执行/内容/完成）实时推送，未连接降级跳过不阻断后台任务、前端断线重连拉取历史对账保证最终一致；开发中靠测试先后捕获并修复工具结果重复落库、SSE 监听器单例串线、双数据源注入抢占等真实缺陷，完整决策与排障过程见仓库开发日志。

项目链接：https://github.com/zaxiu88888/spring-agentforge
