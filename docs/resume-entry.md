# 简历项目条目（精简版 v2，2026-11-06 定稿）

---

AgentForge - AI 智能体助手平台 2026.11- 至今

技术栈：Spring Boot + Spring AI + MyBatis + PostgreSQL/pgvector + React + TypeScript

项目背景：面向知识库问答与自然语言查库场景，从零构建可配置的 AI Agent 平台：自主决策调用工具、多模型动态绑定、SSE 过程实时推送，测试驱动开发（77 个单元/集成测试）。

实现 Think-Execute 决策循环：关闭框架工具自动执行，手动 ToolCallingManager 掌控「思考—执行—结果回填」全流程，全部执行路径单测覆盖；修复参考实现的装配共享状态并发缺陷，多会话互不串扰。

统一 Tool 接口 + 可插拔模型注册：工具按「固定/可选」分类按配置动态装配；SQL 工具四层护栏（白名单/多语句拒绝/强制 LIMIT/只读角色）；模型注册 Bean 名与配置三方对齐加一致性测试，新增模型零侵入。

pgvector 检索链路：Markdown 标题语义分块（策略接口化），自写 TypeHandler 映射向量类型，上传失败整体回滚；知识库列表注入提示词与检索工具构成闭环，Agent 自主选库检索。

SSE 实时推送 + 测试工程：会话级监听器四类事件全链路推送，未连接降级不阻断、断线重连拉历史对账；开发中靠测试捕获并修复重复落库、监听器串线等三个真实缺陷，全过程见仓库开发日志。

项目链接：https://github.com/zaxiu88888/spring-agentforge
